## 🧹 What is AppCleaner?

**AppCleaner** is a lightweight macOS utility developed by **FreeMacSoft** that helps completely uninstall applications.

Simply moving an application to the Trash can sometimes leave related files behind.

AppCleaner helps locate associated files so they can be removed together with the application.

---

## ✨ Features

- 🗑️ Completely uninstall applications
- 🔎 Find associated application files
- 📁 Remove leftover files
- ⚡ Lightweight and fast
- 🍎 Designed for macOS
- 🖱️ Simple drag-and-drop interface
- 🆓 Free to use

## 🖱️ How to Use AppCleaner

Using AppCleaner is simple:

1. Open **AppCleaner**
2. Drag an application into the AppCleaner window
3. Wait while AppCleaner searches for related files
4. Review the detected files
5. Click **Remove**

That's it. ✅

---

## ⚠️ Important

Always review the files selected by AppCleaner before removing them.

Some applications may share files or components with other software.
